# Bases Kanban Companion 1.1.2

Lighter tracking for the embedded open button and compact card layout, and English defaults throughout.

## Changed

- The embedded open button and compact card layout now share one tracker with one observer per Markdown or Bases tab. It reacts only when a Kanban board is added, removed, retargeted or re-rendered. Typing, clicking and other editor changes elsewhere in a note no longer trigger a refresh, and the document `<head>` is no longer observed.
- Compact card layout watches only the tracked Kanban views and their first card for size changes. Theme, font and snippet changes are still picked up through `css-change`.
- The embedded open button is now labeled **Open** (screen readers: "Open board in new tab"), matching the rest of the English interface.
- When no sort option name is set, applying custom value sorting names the generated sort `<property> sort order`. Default names generated by earlier versions are renamed the next time you apply the rule to a Base; custom names are never changed.
- Settings placeholders, README examples and migration notes use generic English examples.

## Compatibility and verification

Desktop only, minimum Obsidian **1.14.4**. No settings changes are required; upgrading only requires replacing the release assets. The embedded open button and compact layout remain enabled only on the tested **1.14.4** build.

Automated tests and bundle checks have passed, including new tests for the shared tracker, ignored editor changes and the refresh limit.

For manual installation, use `main.js`, `manifest.json`, and `styles.css` from the same release. This is an independent community plugin, not an official Obsidian product.
